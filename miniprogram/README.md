# miniprogram — 消费者端微信小程序

面向消费者的溯源查询入口：扫码 / 输入溯源码 → 查看农产品全生命周期记录与质检报告。

## 技术方案

- 微信小程序原生框架（WXML + WXSS + JS）
- 不引入第三方 UI 库，减少包体积，利于通过审核
- 通过 HTTPS 调用后端 REST 接口

```
│   └── format.js         # 时间、状态格式化

```

## 核心页面设计

### 1. 首页 `pages/index`

- 顶部品牌 Banner
- 主操作：「扫一扫溯源」大按钮 → `wx.scanCode`
- 次操作：手动输入 16 位溯源码
- 底部展示"本系统基于 FISCO BCOS 联盟链，数据上链存证"

### 2. 溯源结果页 `pages/trace`

按时间正序展示全链路：

```
[种植] 2026-03-12  山东寿光 · 大棚 A3
  品种：章姬草莓   施肥：有机肥   用药：无
      ↓
[采收] 2026-03-18  采收 120kg · 采收人：李四
      ↓
[检测] 2026-03-20  农残检测合格（报告摘要已上链）
      ↓
[运输] 2026-03-22  冷链运输 2~4℃ · 全程温控正常
      ↓
[销售] 2026-03-23  上架 · 门店：XX 生鲜
```

不合格批次在此处直接显示红色「检测不合格，已拦截」与处置结果，不展示后续销售环节。

每张卡片右下角显示「链上已存证 ✓」，点击可查看交易哈希。

### 3. 环节详情 `pages/detail`

- 图片轮播（种植现场、质检报告照片）
- 质检报告 PDF 在线预览（`wx.downloadFile` + `wx.openDocument`）
- 「数据校验」按钮：后端比对链上哈希与原文，返回一致性结论

## 关键配置

`app.js` 中修改后端地址：

```js
App({
  globalData: {
    baseUrl: 'https://your-domain.com/api'
  }
})
```

`project.config.json` 中填写自己的 AppID。

## 开发调试

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram/` 目录
2. 详情 → 本地设置 → 勾选「不校验合法域名」（仅开发环境）
3. 后端需支持 HTTPS，生产环境在微信公众平台配置 request 合法域名

## 上线注意

- 小程序类目选择「食品」相关需具备资质，溯源工具类可选「工具 - 信息查询」
- 首页需声明数据来源，避免被判定为电商导流
- 所有接口必须 HTTPS，且域名已备案
