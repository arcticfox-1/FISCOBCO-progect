# 技术栈规划

> 版本：v1.0　原则：**够用、稳、教学环境易复现**，不为炫技引入额外复杂度。

---

## 一、选型总表

| 层次 | 技术 | 版本 | 选型理由 |
| --- | --- | --- | --- |
| 联盟链 | FISCO BCOS | **2.9.1** | 2.x 对 Solidity 支持成熟、文档与教学案例最多；3.x 主推 Liquid/C++ 合约，与实训要求的 Solidity 不符 |
| 合约语言 | Solidity | **0.4.25** | 与 2.9.x 控制台默认编译器一致，避免版本不兼容 |
| 链 SDK | fisco-bcos-java-sdk | **2.9.1** | 官方 Java SDK，封装 Channel 连接、签名、回执解析 |
| 后端框架 | Spring Boot | **2.7.18** | 2.x 末版，JDK 8 兼容性好；3.x 要求 JDK 17，部分实验机不便 |
| 运行时 | JDK | **8 (1.8.0_3xx)** | SDK 与 Spring Boot 2.7 的最稳组合 |
| 持久层 | MyBatis-Plus | **3.5.3.1** | 单表 CRUD 免写 XML，复杂查询仍可写 SQL |
| 数据库 | MySQL | **8.0.33** | JSON 字段、窗口函数可用；教学环境普遍已装 |
| 连接池 | HikariCP | 随 Boot | 默认即可 |
| 缓存/会话 | Redis | **6.2**（可选） | 存 JWT 黑名单与批次查询缓存；单机可先不启用 |
| 前端框架 | Vue | **3.4.x** | 组合式 API，生态成熟 |
| 构建工具 | Vite | **5.x** | 冷启动快，配置少 |
| UI 组件 | Element Plus | **2.7.x** | 表格/表单/上传/步骤条齐全，适合管理端 |
| 状态管理 | Pinia | **2.1.x** | Vue 3 官方推荐 |
| 图表 | ECharts | **5.5.x** | 批次状态分布、环节耗时统计 |
| HTTP | Axios | **1.7.x** | 请求拦截统一加 token |
| 二维码 | ZXing | **3.5.2** | 后端生成二维码 PNG，前端直接展示 |
| 文件摘要 | JDK MessageDigest | 内置 | SHA-256，无需第三方 |
| 鉴权 | jjwt | **0.9.1** | 轻量，JDK 8 兼容；配合 Spring MVC 拦截器 |
| 密码 | spring-security-crypto | 5.7.x | 仅用 BCryptPasswordEncoder，不引入整套 Security |
| 文件存储 | 本地磁盘 / MinIO | 本地起步 | 演示规模本地目录足够，接口抽象成 `FileStorage` 便于替换 |
| 消费者端 | 微信小程序原生 | — | 扫码即用、无需下载；文档要求的"扫码查询"由此实现 |
| 文档 | Markdown + Word | — | 交付报告用 Word |

## 二、为什么不用这些

| 备选 | 不采用的原因 |
| --- | --- |
| FISCO BCOS 3.x | 3.x 合约体系改为 Liquid/C++，Solidity 需兼容层，教学资料断层，实训要求明确写 Solidity |
| Hardhat / Truffle | 面向公链/EVM，FISCO BCOS 用官方控制台部署更直接 |
| Spring Security 全家桶 | 只需 JWT + BCrypt，引入完整 Security 配置成本高于收益 |
| JPA / Hibernate | 表结构固定、查询以列表筛选为主，MyBatis-Plus 更可控 |
| uni-app | 只需一个小程序端，原生开发包体更小、调试更直观 |
| IPFS | 演示阶段节点运维成本高，报告文件本地存储 + 摘要上链已满足"完整性可验证" |

## 四、后端依赖清单（pom.xml 关键部分）

```xml
<properties>
  <java.version>1.8</java.version>
  <spring-boot.version>2.7.18</spring-boot.version>
  <fisco-sdk.version>2.9.1</fisco-sdk.version>
</properties>

<dependencies>
  <!-- Web -->
  <dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
  </dependency>

  <!-- FISCO BCOS Java SDK -->
  <dependency>
    <groupId>org.fisco-bcos.java-sdk</groupId>
    <artifactId>fisco-bcos-java-sdk</artifactId>
    <version>${fisco-sdk.version}</version>
  </dependency>

  <!-- MyBatis-Plus + MySQL -->
  <dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-boot-starter</artifactId>
    <version>3.5.3.1</version>
  </dependency>
  <dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
  </dependency>

  <!-- JWT -->
  <dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt</artifactId>
    <version>0.9.1</version>
  </dependency>

  <!-- 仅用 BCrypt，不引入 Security 全家桶 -->
  <dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-crypto</artifactId>
  </dependency>

  <!-- 二维码 -->
  <dependency>
    <groupId>com.google.zxing</groupId>
    <artifactId>core</artifactId>
    <version>3.5.2</version>
  </dependency>
  <dependency>
    <groupId>com.google.zxing</groupId>
    <artifactId>javase</artifactId>
    <version>3.5.2</version>
  </dependency>

  <!-- 工具 -->
  <dependency>
    <groupId>cn.hutool</groupId>
    <artifactId>hutool-all</artifactId>
    <version>5.8.25</version>
  </dependency>
  <dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
  </dependency>
</dependencies>
```

> SDK 具体坐标以你本地 `~/.m2` 实际下载为准。若使用 `fisco-bcos-java-sdk` 3.x 命名，请按官方文档替换，但**版本必须与链的 2.9.1 对齐**。

## 六、链与 SDK 的版本对齐（最容易踩的坑）

| 组件 | 必须一致 |
| --- | --- |
| 链节点版本 | 2.9.1 |
| 控制台 console 版本 | 2.9.x（与节点同系列） |
| Java SDK 版本 | 2.9.1 |
| Solidity 编译版本 | 0.4.25 或 0.6.10（合约顶部 `pragma` 与之一致） |
| SDK 证书 | 从**同一条链**的 `nodes/127.0.0.1/sdk/` 拷贝，不可混用其他链的证书 |

> 证书不匹配的典型报错：`Handshake failed` / `SSL error`。遇到先核对 `ca.crt` 是否来自当前链。
