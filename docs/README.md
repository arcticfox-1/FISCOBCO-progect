## 撰写建议

### 需求分析

- 用 **用例图** 覆盖五类角色：农户、加工企业、物流企业、销售终端、监管方、消费者
- 区分 **功能性需求**（批次管理、溯源查询）与 **非功能性需求**（TPS、上链延迟、数据完整性）

### 系统设计

- 架构图画清三层：应用层 / 服务层 / 区块链层
- 数据库设计给出 E-R 图与核心表结构（`batch`、`trace_record`、`entity`、`product`）
- 说明链上链下数据划分依据

### 测试

- 合约单测覆盖：权限校验、重复写入、越权调用、边界值
- 性能测试：并发上链 TPS、溯源查询响应时间
