## 阅读顺序

1. 先看 **需求分析** —— 明确做什么、谁来做、怎么验收；
2. 再看 **系统设计** —— 架构、表结构、接口，是编码的直接依据；
3. **技术栈** 解决环境与版本问题，**开发计划** 解决节奏问题；
4. **测试方案** 在编码阶段就要对照着写，不要留到最后补。
